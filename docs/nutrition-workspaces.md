# Nutrition workspaces

- Admin / Manager workspace: `/admin/nutrition`
  - View all active clients
  - Decide follow requirement
  - Set priority
  - Assign Nutrition Coach
  - Review and record follow history

- Nutrition Coach workspace: `/nutrition`
  - Shows only clients effectively assigned to the signed-in Nutrition Coach
  - Update workflow status and next follow date
  - Record follow reports and 4R outcomes

The Nutrition API enforces the same assignment boundary server-side for Nutrition Coach users.
